# One board run to close the frontier's last gap

## What's wrong right now

The frontier plot (`results/frontier.png`, row 5.4) recommends **beam 4 @ 24 fps** as the operating
point. Row 5.4 asks for "J per sentence (pose + LM, **measured**)".

Every cell on that plot is **composed**, not measured: `pose_J_per_s × clip_seconds + LM_J`. The only
genuine end-to-end measurement in the project is M1 — beam 4, source-rate clip, 50.37 J. **The cell we
recommend has never been run end-to-end.**

The composition has two known biases in opposite directions:

* **~6 % low** — it predicts 47.2 J where M1 measured 50.37. The convert step (25.7 ms) isn't modelled
  at all, and neither is the idle floor during the 64 s LM load or the warm-up sentence.
* **~7 % high** — `POSE_J_PER_S` came from one clip whose crop is at the 83rd percentile of crop area
  across the 931-clip split, while `CLIP_S` is the mean test-clip duration from our split. The absolute
  column therefore mixes a duration from one split with an energy rate from a different clip.

I have been assuming those roughly cancel. **That assumption is untested, and it is untested precisely
at the cell we're recommending.** If they don't cancel at 24 fps, the plot's absolute axis is wrong and
the "−17 % system energy" headline is wrong with it.

## The run

One pass of `unisign/e2e_translate.py`, same protocol as M1, changing only the frame rate:

```
beam width      4          (same as M1)
frame rate      24 fps     (M1 was source rate)
pose engine     RTMW FP16  (same as M1)
batch size      1          (same as M1 — batching changes the sentence, see §5.1)
repeats         3          (C9 protocol)
```

Please log the same fields M1 logged, plus `cpu0_MHz` — the earlier LM power runs omitted it and it's
needed to rule out a DVFS confound between the two runs.

## What it settles

* **If measured ≈ composed at 24 fps**: the frontier's absolute axis is validated at the operating point
  we actually recommend, and row 5.4's "measured" requirement is genuinely met rather than argued
  around.
* **If they diverge**: we learn the biases don't cancel, and the fix is a scale correction applied
  uniformly — the *relative* ordering across cells survives either way, because every cell shares the
  same clip and the same rates. The recommendation itself is not at risk; only the absolute joules are.

Either outcome is worth more than any remaining accuracy experiment on my side, which is why I've
stopped running those.
